# World Cup 2026 Tracker

A personal project for fun -- a lightweight, single-page World Cup betting tracker built with vanilla HTML, CSS, and JavaScript. No dependencies, no build step.

## Usage

Open `index.html` in any browser. No server required.

To deploy, push to GitHub and enable GitHub Pages from the `main` branch root.
